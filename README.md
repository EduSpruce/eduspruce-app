# eduspruce.app

- **Raiz** (`index.html`): página de apresentação do EduSpruce. Quem já usava a app neste endereço (instalada no ecrã principal ou com dados guardados) e o regresso do início de sessão Google/Microsoft seguem automaticamente para `app/`. Para ver sempre a apresentação: `https://eduspruce.app/?landing`.
- **`app/`**: cópia da app que envia para a nuvem o que estiver por sincronizar e muda para **https://eduspruce.pt**. O endereço de regresso do início de sessão continua a ser `https://eduspruce.app/` (a raiz reencaminha).

O código principal está em [EduSpruce/EduSpruce](https://github.com/EduSpruce/EduSpruce).
